# Audio Assets

Place your audio files here to enable sound in the experience.

## Required Files

### Background Music
- `ambient.mp3` — looping ambient track, plays continuously after user interaction

### Sound Effects
- `transition.mp3` — subtle whoosh when the active section changes (~0.3s)
- `camera-move.mp3` — soft mechanical click when the camera path hits a keyframe (~0.2s)

## Format Recommendations

- **MP3** for broad compatibility
- Background music: ~128 kbps, stereo, looping without clicks
- SFX: mono, 44.1 kHz, normalized to -6 dB peak so they sit under the music

## Placeholder Behavior

Until you add these files, the audio system is wired but silent — no errors, no console noise, just no sound. Drop the files in and reload.
